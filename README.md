# Amazon Prime Video Data Analysis Project

## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on the Amazon Prime Video dataset to discover trends in movies and TV shows, genres, and IMDb ratings.

## 🚀 Live Demo
You can view and run the interactive notebook directly on Google Colab:

## 📊 Key Insights
- **Total Visualizations:** 20 Charts covering various aspects of the data.
- **Top Genres:** Drama and Comedy are the most frequent.
- **Content Trends:** Significant increase in content library since 2015.
- **Rating Analysis:** TV Shows generally have higher average IMDb scores than Movies.
